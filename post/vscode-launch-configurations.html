[VSCode 學習筆記] - 執行組態

2024-01-08T02:24:46.000Z2024-09-08T02:38:48.198Z1.1k4 min

在 VSCode 中，執行組態是用於配置調試環境的重要檔案。透過這個檔案，開發者可以設定如何啟動和調試應用程式，使得調試過程更加高效和靈活。在本文中，我們將介紹如何創建和使用執行組態。

執行組態是一個命名 launch.json 的檔案，它是 VSCode 調試配置的主要檔案，它包含了所有的調試設定，包括要調試的程式、執行的參數、工作目錄等。使用這個檔案，開發者可以輕鬆定義不同的調試環境，並根據需要進行切換。

創建執行組態

開啟 VSCode，於左側選單列中選取「執行與偵錯」，然後再按「建立 launch.json 檔案」。

它會要求你選用哪一個偵錯工具，請依照你的項目需求而決定，在本文中，我們會使用 Node.js 作為範例。

然後它會自動開啟了 launch.json 檔案，你可以在右下角點擊「新增組態」來新增內建通用的組態項。

它會在自動補全選單中顯示可用的組態項，這裏你可見它內建一些 Node.js 的組態項：

編寫執行組態

現在試試編寫一個簡單的組態項，這個組態項會先啟動終端機，並新增新的會話，然後在當前會話中執行初始化 NPM 的指令。

如果你想創建全域的執行組態，你需要在 settings.json 檔案中編寫組態項。

一旦新增了組態項，你可以在「執行與偵錯」控制板中的下拉式選單，找出剛才所建立的組態項，當你想執行當前下拉式選單選擇的組態項，你可以按旁邊的「▷」按鈕執行。

設置輸入元素

在組態 configurations 區域外，可新增 inputs 區域，這個區域用於設置輸入元素，然後可透過 ${input:id} 語法來擷取該值。

輸入文字

例如，當要編寫一個安裝 NPM 套件的組態項時，我們需要提供一個輸入框讓用戶輸入套件名稱，從而能夠成功安裝，這時候就需要使用 promptString 類型元素，這類型用於輸入文字。

加入選項

有時候，當我們需要用戶選擇某些選項，例如繼續以安裝 NPM 套件為例，我們可以新增選項，決定要以生產模式還是開發模式來安裝，我們會用 pickString 類型元素。

設置複合組態

我們可以在 compounds 區域內設置現有組態，這個複合組態會一併執行多個組態項。例如，我們可以利用這個功能初始化一個 React 項目。

你可以為組態項內的 presentation 加入 hidden 屬性，來設置該組態項隱藏與否，這會影響到下拉式選單的顯示。

考慮不同操作系統

需知道操作系統有許多種，如 Windows、Linux 及 macOS 等，而許多時候，安裝套件的指令碼也是不同的，因為有些操作系統倚賴套件管理器，如果這個組態檔案不是只給自己使用的話，那你需要考慮不同操作系統的情況。
