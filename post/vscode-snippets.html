[VSCode 學習筆記] - 程式碼片段

2022-12-31T14:03:21.000Z2024-09-07T09:46:31.340Z3.5k13 min

程式碼片段 (Code Snippets) 是許多整合開發環境軟件 (IDE) 都會提供的功能，它可讓開發者快速輸入常用的程式碼，以提高開發效率。在本文中，我們會使用 VSCode 來學習如何創建及使用程式碼片段，若你是在使用其他文本編輯器或 IDE，編寫程式碼片段的概念其實大同小異，可作參考。

雖然 VSCode 不是一個 IDE，而是一個文本編輯器，但借助延伸模組的支援，許多開發語言集成模組 (Language Integration Extensions) 都會提供附建的程式碼片段，透過多元的智能代碼補全 (IntelliSense)，使 VSCode 逐漸變得強大，可謂雨後春筍。

不過，即使部分開發語言集成模組提供了程式碼片段，有時候也會覺得限制多多（始終是別人寫，人家不知道你的要求），因此，我們可以創建自訂的程式碼片段，當有更大的需求時，我們也可以隨時修改，以彰顯程式碼片段的威力，同時亦把自己的慵懶發揮得淋漓盡致。。。

創建程式碼片段

首先開啟 VSCode，在「檢視」 > 「命令選擇區」開啟命令選擇區。

在命令選擇區內輸入 snippets 以搜尋「程式碼片段：設定程式碼片段」，並點擊它。

接着，你會看到這個視窗，你可以因應需求，選擇全域還是在當前工作區內新增程式碼片段檔案。

在當前工作區，即是只有當前項目可使用，通常是為項目的功能所需而編寫的程式碼片段，例如我撰寫 Hexo 網誌，除了編寫全域 Markdown 程式碼片段外，也會在工作區編寫標籤外掛的程式碼片段，方便撰寫內容。

當前工作區會自動產生 .vscode 目錄，裏面存放了剛才所建的程式碼片段檔案，該檔案亦自動寫入了官方的指引。

在所有工作區內都可使用，即是整個 VSCode 軟件開啟任何項目都可使用，這些通常是為特定語言編寫通用的程式碼片段，例如，我自己編寫了 Markdown 的程式碼片段，檔案為 markdown.code-snippets。

如果你想找到全域程式碼片段的儲存位置，你可以先開啟 settings.json，然後在檔案路徑導覽列中找出 snippets 目錄，裏面就是所創建的全域程式碼片段。

你也可以指定程式碼片段使用整套編程語言，例如你選擇 CSS，便會在全域資料夾內產生 css.json。相當於使用全域方式創建，但檔案名稱決定指定整套編程語言。

選擇全域還是當前工作區後，輸入程式碼片段的檔案名稱，例如 my-snippets。

編寫程式碼片段

你可以使用 snippet-generator 輕鬆創建程式碼片段，然後把寫好的內容貼上到程式碼片段檔案內。如果你不太熟悉或嫌麻煩寫 JSON 語法，可以使用這個工具，採用人性化的介面建立程式碼片段。

你也可以直接編輯程式碼片段檔案，依照 VSCode 程式碼片段官方文檔的指引及格式，透過 JSON 語法編寫。

  • Description：程式碼片段的描述，說明這個程式碼片段產生的程式碼的主要用途。
  • Tab Trigger：對應 JSON 的 prefix 屬性，用作設置觸發程式碼片段的前置詞。
  • Your snippet：對應 JSON 的 body 屬性，用作設置程式碼片段的內容。

snippet-generator 讓你輕易創建簡單的程式碼片段，所以功能有限制，當你需要設置其他屬性時，你還是需要手動編輯程式碼片段檔案。

設置預留位置

一個程式碼片段的好用程度是在於它彈性如否，就像我們現在剛才寫的程式碼片段就是不好用，因為 console.log() 內的值固定了「Hello World」，如果我們能夠在插入程式碼片段後，游標會停留在 console.log() 函數括號內供我們輸入內容，那麼這個程式碼片段便會好用很多。

有了這個想法後，我們可以在 body 屬性內使用 $ 設置預留位置。

  • $0：用於設置游標的最終位置，不一定需要，因為如果沒有使用 $0 特別指明該位置，會以程式碼片段的最後一個字元為最終位置。
  • $1、$2 等等：用於設置作用域需停留的位置。

在插入程式碼片段後會進入編輯模式，這個時候，游標會停留在程式碼片段所設定的首個預留位置位置，期間，你可以為預留位置編輯任何文字。

  • Tab：切換至下一個游標位置
  • ⇧Shift + Tab：切換至上一個游標位置

當程式碼片段只需要一個預留位置，通常也是一些較簡單的程式碼，你可以不需要指明預留位置名稱。

當程式碼片段插入的程式碼過於複雜時，我們需要指明預留位置名稱，說明預留位置的作用，讓開發者易於理解。

設置選項

雖然我們可以使用預留位置，為 console.log() 輸入字串，，但是預留位置只能靠我們手動輸入，無法為程式碼加入一些可提供的功能，為了讓用戶易於理解程式碼應使用的字串、函數等，那麼我們可以把它們新增為選項，讓這個程式碼片段的可用性大增。

使用變數

在某些情況下，我們不要求用戶輸入或選擇內容，而是根據其他可用資料，以完成程式碼。在 VSCode，它提供了一些變數，這些變數會在插入程式碼片段後，自動替換為相應的值。

變數 描述
$TM_SELECTED_TEXT 目前選取的文字或空字串
$TM_CURRENT_LINE 目前行的內容
$TM_CURRENT_WORD 游標所在單字的內容或空字串
$TM_LINE_INDEX 以零為起始的行號
$TM_LINE_NUMBER 以一為起始的行號
$TM_FILENAME 目前文件的檔名
$TM_FILENAME_BASE 目前文件不含副檔名的檔名
$TM_DIRECTORY 目前文件的目錄
$TM_FILEPATH 目前文件的完整檔案路徑
$RELATIVE_FILEPATH 目前文件相對於已開啟工作區或資料夾的檔案路徑
$CLIPBOARD 剪貼簿的內容
$WORKSPACE_NAME 已開啟工作區或資料夾的名稱
$WORKSPACE_FOLDER 已開啟工作區或資料夾的路徑
$CURSOR_INDEX 以零為起始的游標號碼
$CURSOR_NUMBER 以一為起始的游標號碼
